# Edén La Radio V4

Versión tipo app profesional para GitHub Pages.

## Cambios incluidos
- Logo PNG con fondo transparente.
- Se quitó el texto grande “Edén La Radio” de la pantalla principal.
- Tarjeta de reproducción limpia: artista + título solamente.
- Evita mostrar logo del proveedor del streaming como portada.
- Secciones tipo páginas: Inicio, Palabra, Versículos pasados, Donaciones, Tienda y Redes.
- Idioma automático según dispositivo: español/inglés.
- Responsive: teléfono se ve como app, desktop como web.

## Subir a GitHub
1. Abre el repositorio `eden-la-radio`.
2. Presiona **Add file** → **Upload files**.
3. Sube todo el contenido de este ZIP.
4. Acepta **Replace files**.
5. Presiona **Commit changes**.
